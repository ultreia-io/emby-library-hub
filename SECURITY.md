# Security policy

The supported release line is 0.1.x, targeting Emby Server 4.11.0.5 on .NET 8.

Report suspected vulnerabilities privately to the maintainer before disclosing details publicly.

After GitHub publication, use private vulnerability reporting if enabled under the repository's Security tab.

Do not include SMTP passwords, subscriber addresses, authentication tokens, or private archive links in public issues.

See [privacy and security](docs/security.md) for authenticated share links and data stored by the plugin.
