# Library Hub 0.1.1

Fixes report responses, adds version and GitHub footers, and includes bilingual administrator and user guides.

## Fixes and interface

- Report generation now returns its result or validation message after waiting for ongoing library work.
- The same response fix covers archive viewing, preview, reset, and subscriber administration.
- Every plugin and documentation page footer shows the release version.
- Every plugin page footer links to the GitHub repository, including saved archive pages when opened.
- Saved archive pages display the installed version when opened, without rewriting the stored reports.

## Documentation

- English and French administration guides covering installation, access, archives, email, backups, and updates.
- English and French user guides covering sign-in, browsing, searching, daily reports, and subscriptions.
- Three administration diagrams and eight screenshots per language, with fictional demonstration data.
- Navigation organized by audience, plus separate archive administration instructions.
- Simple DLL installation instructions without hardcoded plugin versions.
- Clearer explanations of the shared archive, per-user browsing permissions, and subscriber email delivery.
- Improved guide buttons in the dark theme and reproducible tools for all documentation visuals.
- Removed the maintainer's Emby submission preparation page from the documentation.

Member screenshots use the plugin UI. Administration captures use its actual controls in a local preview layout.

## Compatibility and upgrade

The plugin now targets **.NET Standard 2.0**. The API baseline remains **Emby Server 4.11.0.5**.

Assembly version: **0.1.1.0**.

Plugin loading and archive generation were verified on Synology with Emby **4.11.0.6**.

Other server versions and platforms still need validation.

Mail dependencies and their runtime support assemblies are embedded, with licenses included in the DLL and ZIP.

Settings and stored data formats are unchanged from 0.1.0. No data migration is required.

To update, stop Emby, back up the configuration and all of `data/library-hub/`, then replace `Emby.LibraryHub.dll`.

Keep the old DLL outside the plugin directory. Restart Emby and verify the plugin version and a known report.

## Existing access limits

All signed-in members share the saved archive, including every reported library.

Browsing and subscriber emails follow each member's Emby permissions.

This release adds no native Android or TV integration. Use Library Hub in a browser when its app menu is unavailable.
