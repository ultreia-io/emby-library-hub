# Library Hub 0.1.0

First release of Library Hub for Emby: browse libraries, read daily archives, and subscribe to email updates.

## Browse and search

- Separate Browse and Search pages, with one fixed control card on each page.
- Full catalog browsing with lazy groups, series, seasons, and optional episodes.
- Search by title, synopsis, actor, director, genre, tag, studio, year, or all metadata.
- Case- and accent-insensitive matching; title search is the default and requires at least two characters.
- Optional episode metadata search, filters, sorting, and explanations for metadata matches.
- Administrators choose offered libraries; members select a subset within their Emby permissions.
- Collections appears as one library, with box sets inside it.

## Archives and subscriptions

- Daily additions and removals grouped by library and calendar day, with movie and series links.
- Private HTML archive with monthly navigation and standalone shareable URLs.
- Date-range generation and archive reset with backup, without triggering emails.
- Account-bound signup, email confirmation, language choice, and unsubscribe controls.
- Subscriber administration and persisted daily delivery and retry state.
- At most one successfully recorded daily report per address per calendar day; empty days are skipped.

## Administration and installation

- French and English interface and documentation; settings follow Emby's display language.
- Remembered browser sessions and reuse of the same-origin Emby Web login.
- SMTP TLS on port 465 and STARTTLS on other ports.
- Configuration import/export and a single DLL with embedded mail libraries.
- GPL-3.0-only license, CI, documentation website, and draft-release workflows.

Targets Emby Server 4.11.0.5 on .NET 8. Assembly version: **0.1.0.0**.

Install `Emby.LibraryHub.dll` while Emby is stopped, then restart it and refresh the browser.
Keep the plugin configuration and data directories when replacing a development build.
Do not copy Emby SDK assemblies into the plugin directory.

## Access and known limits

All signed-in Emby members share the same saved archive, including every reported library.
Browsing and subscriber emails respect each member's current Emby permissions.

Historical additions rely on Emby creation metadata; removals before tracking started cannot be reconstructed.
Deleted titles are omitted from emails when fine-grained access cannot be verified.

Native TV clients may hide custom plugin menus. Browsing, signup, and reports are available in a web browser.
Metadata searches scan accessible items in batches; response time depends on library size.

SMTP acceptance and local delivery records are not transactional. An uncertain send can cause a retry duplicate.

The plugin is not yet listed in Emby's official catalog and is not endorsed by Emby.
